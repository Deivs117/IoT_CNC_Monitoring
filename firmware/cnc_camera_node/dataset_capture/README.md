# Dataset ESP32-CAM — IoT CNC PCB Monitor

Carpetas de imágenes organizadas por clase para entrenamiento en Edge Impulse.

```
dataset/
├── PCB_Mixta/    ← PCB con componentes SMD + Through-Hole
├── PCB_SMD/      ← PCB exclusivamente SMD
├── PCB_TH/       ← PCB exclusivamente Through-Hole
└── Sin_PCB/      ← Bancada vacía
```

Esta carpeta es generada por `capture.py` y está excluida del control de versiones.
